# Assignment 4: Writing Functions

## 1. Experiment Title

Functions, Arrow Functions and Default Parameters.

## 2. Aim

To write a function with a return value, an arrow function, and a function with a default parameter.

## 3. Software / Tools Required

- Programming Language: JavaScript (ES6+)
- Web Browser: Google Chrome (with the Console in Developer Tools)
- IDE / Text Editor: Visual Studio Code (VS Code)

## 4. Theory

A function is a reusable block of code that can take inputs and return a result.

The following concepts are used in this experiment:


1. A function is declared with the function keyword, receives parameters and gives back a value with return. An arrow function is a shorter way of writing a function using =>.

2. A default parameter gives an argument a value that is used when the caller does not pass one, for example function f(a, b = 2).


## 5. Algorithm / Procedure

### Task 1: greet function

1. Start the program.

2. Create function greet(name) that returns "Hello, " + name.

3. Print greet("Asha").

4. Stop.


### Task 2: Arrow function square

1. Start the program.

2. Create the arrow function square that returns n * n.

3. Print square(6).

4. Stop.


### Task 3: Default parameter

1. Start the program.

2. Create billWithTax(amount, taxRate = 0.18) returning amount + amount * taxRate.

3. Print billWithTax(100).

4. Stop.


## 6. Input

The following values are used in the experiment:


### Task 1:
name = Asha.


### Task 2:
n = 6.


### Task 3:
amount = 100; default taxRate = 0.18.


## 7. Output

### Task 1:
```text
Hello, Asha
```


### Task 2:
```text
36
```


### Task 3:
```text
118
```
