# Assignment 1: Your First JavaScript Script

## 1. Experiment Title

Running a First JavaScript Script and Declaring Variables.

## 2. Aim

To run a script in the browser, declare values with const and let, and find the type of a value using typeof.

## 3. Software / Tools Required

- Programming Language: JavaScript (ES6+)
- Web Browser: Google Chrome (with the Console in Developer Tools)
- IDE / Text Editor: Visual Studio Code (VS Code)

## 4. Theory

JavaScript is a high-level programming language used to make web pages interactive.

The following concepts are used in this experiment:


1. console.log() prints a value to the console. A script can run in a browser inside a script tag (output is seen in the Console, opened with F12).

2. const declares a constant whose value cannot be changed, and let declares a variable whose value can be changed. The typeof operator returns the type of a value, such as string, number or boolean.


## 5. Algorithm / Procedure

### Task 1: Hello from the script

1. Start the program.

2. Create an HTML page with a script tag in the body.

3. Print Hello from the script with console.log.

4. Open the page and check the Console (F12).

5. Stop.


### Task 2: const and let

1. Start the program.

2. Declare const schoolName = "Sample College".

3. Declare let year = 2026.

4. Print both values on separate lines.

5. Stop.


### Task 3: typeof

1. Start the program.

2. Print typeof "hello".

3. Print typeof 7.

4. Print typeof true.

5. Stop.


## 6. Input

The following values are used in the experiment:


### Task 1:
Text = Hello from the script.


### Task 2:
schoolName = Sample College; year = 2026.


### Task 3:
Values = "hello", 7, true.
