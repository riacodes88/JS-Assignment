# Assignment 2: Operators, Type Conversion and a Calculator

## 1. Experiment Title

Arithmetic Operators, Type Conversion and Choosing an Operation.

## 2. Aim

To use arithmetic operators, convert between text and numbers, and use if and else if to choose an operation.

## 3. Software / Tools Required

- Programming Language: JavaScript (ES6+)
- Web Browser: Google Chrome (with the Console in Developer Tools)
- IDE / Text Editor: Visual Studio Code (VS Code)

## 4. Theory

Operators perform calculations and comparisons on values.

The following concepts are used in this experiment:


1. The arithmetic operators are + (add), - (subtract), * (multiply), / (divide) and % (remainder). The + operator joins text when one value is a string.

2. Number() converts text to a number and String() converts a number to text. The if and else if statements run a block of code according to a condition, and === compares two values.


## 5. Algorithm / Procedure

### Task 1: Arithmetic operators

1. Start the program.

2. Store 17 and 5 in variables a and b.

3. Print a + b, a - b, a * b and a / b.

4. Stop.


### Task 2: Type conversion

1. Start the program.

2. Convert the text "12" to a number with Number() and add 5.

3. Convert the number 7 to text with String() and join it with "3".

4. Print both results.

5. Stop.


### Task 3: Simple calculator

1. Start the program.

2. Store 8 and 4 and the operator +.

3. Use if and else if to print the sum for + or the difference for -.

4. Change the operator to - and repeat the check.

5. Stop.


## 6. Input

The following values are used in the experiment:


### Task 1:
a = 17; b = 5.


### Task 2:
Text = "12"; number = 7.


### Task 3:
Numbers = 8 and 4; operators = + and -.
