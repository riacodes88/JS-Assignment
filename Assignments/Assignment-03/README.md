# Assignment 3: Conditions and Loops

## 1. Experiment Title

Decision Making and Loops in JavaScript.

## 2. Aim

To choose between cases with if, else if and else, and to repeat work with a for loop and a while loop.

## 3. Software / Tools Required

- Programming Language: JavaScript (ES6+)
- Web Browser: Google Chrome (with the Console in Developer Tools)
- IDE / Text Editor: Visual Studio Code (VS Code)

## 4. Theory

Conditions let a program make decisions and loops let it repeat work.

The following concepts are used in this experiment:


1. The if, else if and else statements check conditions one after another and run the first block whose condition is true. Comparison operators such as >= are used in the conditions.

2. A for loop repeats code a fixed number of times using a start value, a condition and an update. A while loop repeats as long as its condition is true, so the variable in the condition must be updated inside the loop.


## 5. Algorithm / Procedure

### Task 1: Grade from marks

1. Start the program.

2. Store the marks 72.

3. If marks >= 75 print Grade A, else if marks >= 60 print Grade B, otherwise print Grade C.

4. Stop.


### Task 2: for loop

1. Start the program.

2. Use a for loop with i from 1 to 5.

3. Print i on each pass.

4. Stop.


### Task 3: while loop

1. Start the program.

2. Set total = 0 and n = 1.

3. While total is not more than 20, add n to total and increase n by 1.

4. Print the total.

5. Stop.


## 6. Input

The following values are used in the experiment:


### Task 1:
marks = 72.


### Task 2:
Range = 1 to 5.


### Task 3:
Limit = 20.
